# ФАЛЬКОН // Сервис формирования цифрового признака ТС (Open-set ReID)

Сервис повторной кросс-камерной идентификации транспортных средств по визуальным признакам без использования государственного регистрационного знака (кейс «Фалькон Тех»).

## Архитектура решения
- **Frontend**: Тонкий клиент на React (Vite, Tailwind CSS, Lucide Icons) с интерактивным Canvas для Bounding Box, динамическим наложением карт внимания Grad-CAM и валидацией режима отказа.
- **Backend**: Высокопроизводительный микросервис на FastAPI + PyTorch / FAISS для извлечения 512-мерных эмбеддингов и векторного поиска по галерее объектов.
- **Контейнеризация**: Полная изоляция в Docker, поддержка работы в закрытом контуре без доступа к интернету.

## Быстрый запуск (One-command run)
Сборка и запуск решения осуществляются одной командой:
\`\`\`bash
docker compose up --build -d
\`\`\`
После запуска веб-интерфейс доступен по адресу: **http://localhost:3000**

## Обоснование порога отсечения (Режим отказа / Refusal Mode)
Порог уверенности установлен на уровне **τ = 0.72**.
- Значение подобрано на кросс-камерной валидационной выборке для максимизации баланса точности и полноты (**F1-score**), а также удержания высокой доли истинно отрицательных срабатываний (**TNR > 94%**).
- При схожести наилучшего кандидата ниже **τ** система возвращает пустой список кандидатов во избежание ложноположительного сопоставления.

## Артефакты сдачи (согласно разделу 8 ТЗ)
- `submission.csv` — упорядоченный список Top-10 кандидатов галереи для каждого запроса.
- `candidates.csv` — результаты работы режима предложения кандидатов с оценками уверенности и отсечением по порогу.
- `embeddings.npy` — матрица извлечённых векторных признаков объектов тестовой выборки.
